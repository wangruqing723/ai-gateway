ChatGPT 账户共享约束

同一 OAuth 账户绑定的全部 Provider 共用这些上限，所有账户使用同一组设置

直通模式跳过本地排队，并发与速率上限不生效；共享额度冷却仍然生效。

共享额度冷却：上游返回 HTTP 429 且错误类型为 usage_limit_reached 时，账户按上游给出的重置时间冷却（未给出时 60 秒，最长 30 天）， 同账户全部 Provider 暂停准入。冷却只在本进程内存中，可在账户详情手动解除；关闭此开关会清除全部冷却。

ChatGPT 后台刷新

为活跃的 ChatGPT OAuth 账户在后台预刷新访问令牌、定期刷新用量；默认全部关闭，关闭时不产生任何后台请求

后台状态

活跃账户：本进程在活跃窗口内为它发起过真实上游调用，且未暂停、不需要重新授权、有 refresh token。闲置、暂停和需要重新授权的账户不产生后台请求。

失败退避：令牌从 1 分钟起翻倍，最长 60 分钟；用量从一个周期起翻倍，最长 24 小时，上游给出更长的 Retry-After 时以它为准。网络故障不会标记重新授权；人工刷新、诊断和请求路径的按需刷新不受退避限制，任何一次成功都会清零失败计数。

多个实例共享账户文件时依靠文件锁互斥；宿主机进程与容器混合部署共享同一账户文件时不保证互斥，请避免这种部署。
