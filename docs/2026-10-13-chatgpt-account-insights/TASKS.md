# ChatGPT 账号授权与用量信息

## 目标

在管理页面的 ChatGPT 账号列表中展示每个账号的授权时长、可识别的账号/套餐类型、剩余用量和用量重置时间，并保留现有状态、绑定提供商及删除操作。

## 已确认的实现假设

- “授权时长”按首次绑定时间及从首次绑定至今的时长展示；访问令牌过期时间不代表账号授权时长或订阅截止时间。
- 若 OpenAI 返回订阅生效/截止时间声明，则额外展示；没有声明时不推算。
- 剩余用量按上游实际返回的限额窗口计算，只显示可用窗口及其重置时间；不假定固定的小时/周配额。
- 已存在且没有首次绑定时间的账号显示“未知”，不以本次升级或重新授权时间伪造历史。
- 用量信息通过后端查询并缓存，浏览器不接触 access token 或 refresh token。查询失败不影响账号列表和授权调用。

## 验收标准

- 账号列表能显示授权日期和已授权时长；历史数据缺失时明确显示未知。
- 套餐/账号类型使用可获得的上游字段显示，字段缺失时不猜测。
- 剩余用量与重置时间来自上游实际额度窗口，所有可用窗口均可区分显示。
- 用量服务异常时仍可查看账号列表、状态和绑定提供商，且错误状态可理解、可重试。
- 任何 API 响应、浏览器状态和日志均不包含 access token 或 refresh token。
- OAuth 重新授权不会重置首次授权时间。
