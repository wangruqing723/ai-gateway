# 账户独立预检与批量预检设计

创建日期：2026-11-08。用户已确认 TASKS.md 的 D01–D05，本文记录实现约束。

## 1. 当前实现与复用边界

- `cmd/gateway/chatgpt_diagnose.go`：本地检查、刷新、用量、实际调用有固定顺序；本地检查始终执行。实际调用要求已保存 Provider 绑定，通过 `forwardAttempt` 复用转发，输出受限，不计入普通日志与指标，也不上报熔断器。
- `chatGPTDiagnosePrompt` 当前为 `Reply with OK.`；单账户总预算为 45 秒，输出上限为 256 token，整个诊断请求体当前限制 4 KiB。增加测试内容后必须同时调整请求体限制，不能只放宽字段长度。
- `cmd/gateway/chatgpt_batch.go` 与 `internal/chatgptauth/usagebatch.go`：已有批量管理预检与批量用量刷新，但没有批量实际调用。用量刷新并发为 3、最多 50 个账户、总预算 60 秒，不能直接将该总预算用于批量诊断。
- `internal/chatgptauth/catalog.go`：提供目录凭据获取、刷新锁、轮换安全落盘与凭据身份校验；暂停账户可以查目录，目录不记为调用。
- `internal/providermodels`：已有目录解析、串行化查询租约、缓存与限流退避。当前缓存按 Provider 索引并随 Provider 配置清理，新增账户入口不能混入同一命名空间。
- `cmd/gateway/web/src/app/12-routes.js.part`：已有模型选择器及目录获取逻辑，但查询入口依赖 Provider 配置。应扩展为明确来源，不伪造 Provider 或把账户 ID 塞进 Provider 名称。
- `cmd/gateway/main.go`：管理 OAuth 客户端通过 `httpclient.Pool` 解析 `AI_GATEWAY_OAUTH_PROXY`，再注入账户管理器。新路径继续复用该代理口径。

## 2. 检测模式与内容语义

### 独立账户预检

以账户 ID 为身份，不要求绑定。官方 Codex 基地址固定为 `https://chatgpt.com/backend-api/codex`，请求协议沿用项目现有 OAuth 实际调用适配，不用通用 Chat 请求替代。公开接口不得传入上游地址、代理、令牌或额外请求头。

账户预检沿用 OAuth 管理代理；没有专用代理时使用现有环境代理口径。不会自动挑选某个绑定 Provider，也不会修改配置。

独立预检不进入 Provider 队列、不报告 Provider 熔断、不参与负载均衡和故障转移。执行前检查账户暂停和现有账户级准入；复用账户并发及冷却约束，不以诊断名义绕过。即使账户从未绑定，也必须有有界准入，不借虚构 Provider 名称留下队列状态。

复用或最小提取现有 OAuth 请求准备、凭据 ticket、协议改写与调用结果分类能力。不建立另一套凭据刷新或令牌持久化逻辑。不为本需求重构普通请求的路由架构。

### Provider 链路诊断

保留当前实现：已保存绑定关系是准入条件；地址、代理、队列、额外请求参数和账户获取路径仍来自所选 Provider。用户自定义测试内容替代默认输入文本，其余边界不变。输出上限仍须在 Provider 参数合并后生效。

### 测试内容

字段为 `prompt`。字段缺省、空字符串或仅空白使用既有默认内容；非空时按原样发送，不去掉首尾空白或换行。拒绝无效 UTF-8、NUL 及超过确认上限的内容，保留正常换行和制表符。

字段上限按 UTF-8 字节计算，前后端一致。JSON 编码可能转义字符，因此请求体上限需覆盖全部字段及最坏合法转义开销，单次和批量均为 64 KiB。

测试内容仅为本次临时文本消息，不支持文件、图片、工具、系统指令编辑或多轮会话。不会写入本地存储、账户文件、诊断报告和日志。关闭弹窗清空内容。模型输出仍丢弃，仅判定协议成功或失败；不要求模型必须回复 OK，也不增加输出内容匹配规则。

## 3. 账户级模型目录

新增账户级目录入口；复用固定官方目录地址、client_version 默认值、解析器与缓存退避。管理客户端必须禁用跨站凭据重定向和 cookie 注入，沿用现有安全请求构建规则。

为账户目录使用独立缓存实例，键为账户 ID，连接指纹包含实际目录连接语义，身份使用 CatalogIdentity。沿用既有目录 TTL 和失败退避，不在浏览器持久缓存 OAuth 目录。

账户删除、凭据替换、重新授权、同 ID 重建及运行时清理后，不返回旧身份目录；缓存不得随历史账户单调增长。删除时主动清理，迟到结果不得重建已移除条目，补并发回归。

仅用户打开目录选择器或明确刷新时查询。打开诊断弹窗、选中实际调用步骤、选定账户集合都不自动查询全部账户。

批量目录来源须显式选择一个本批账户。显示“目录来自此账户，不代表其他账户拥有同样权限”；其他账户按统一模型实际测试，权限不同返回逐项结果，不自动换模型。

## 4. 批量执行与进度

仅批量运行独立账户预检，不根据绑定情况自动切换 Provider 模式。

批次开始时冻结账户 ID、步骤、刷新模式、模型和测试内容。后端先完成整批结构与确认字段校验，再启动有界 worker pool；按提交顺序排队，结果携带原索引，完成事件按完成顺序发送。

已确认约束：最多 50 个账户、并发 3、单账户从实际开始执行起 45 秒、整批 15 分钟。超时与主动取消分开记录，但均不等同于账户失效。整批最多一个在运行的诊断批次，进程内 gate 生命周期用 defer 收口。

单账户与批量复用相同账户诊断互斥，防止重复实际调用；与已有用量刷新和后台维护仍依靠账户刷新锁及调用 ticket 保证安全，不新增全局凭据锁。

暂停账户本地检查可执行，批量出网步骤跳过。账户忙碌或执行中被删除返回逐项状态，其他账户继续。任务获得执行槽后、每一步出网前重新核对账户身份、暂停和取消，防止排队期间的变更被忽略。

服务端用 POST 流式响应推送开始、逐账户结果及结束汇总。前端以 fetch 流读取，不使用无法提交请求体的原生 EventSource。客户端取消中止连接，服务端取消 context，停止派发并取消在途等待；已发送请求可能消耗额度，已完成轮换必须保留。

浏览器保留已经收到的安全结果，未收到的在途结果显示“已取消等待，结果未知”，不能伪称服务端已撤回。刷新或断线后不自动恢复和重发批次，不提供后台任务持久化。

## 5. 状态、隐私与兼容

- 账户模式实际调用写入账户最近调用记录，增加来源区分，不能把空 Provider 显示成损坏记录。
- 单账户旧请求带 provider 且无 mode 时保持 provider 语义；新前端显式发送模式，避免默认变化误测另一条链路。
- 账户模式不接受 provider；Provider 模式必须携带并验证绑定。
- 未选择 inference 时不接受调用专属参数，不能静默忽略；默认本地检查不能被其他字段偷偷升级为出网。
- 单个模型错误只描述此模型调用；目录查询、用量查询、授权和实际调用结果仍独立展示。
- 真实上游错误正文、令牌、代理凭据、请求文本和模型输出不得写入诊断响应及事件。
- 调用记录更新使用现有凭据世代保护，旧 ticket 不能覆盖新授权状态。
- 自定义内容、模式、模型、Provider、账户选择集、目录来源及检查步骤变化均取消消费确认。

## 6. 界面

单账户弹窗明确区分“账户预检”和“Provider 链路诊断”，新打开默认账户预检；只有 Provider 模式显示绑定选择。实际调用选项下展示模型、目录入口、选填多行测试内容及默认值说明。

账户列表增加“批量预检”，仅作用于勾选账户，显示本次快照数量，不默认选全部。复用已有选择和筛选交互，但不复用具有管理变更含义的 previewToken。

批量结果按账户展示各检查步骤、代理来源、耗时及状态，不只给一个健康布尔值。运行中锁定输入，显示完成数与总数，保留取消按钮。消费确认文案明确本批可能逐账户产生费用。

目录下拉保持现有搜索、手填、刷新、取消与键盘交互。诊断弹窗内列表不得覆盖消费确认；ESC 优先关闭模型列表，再关闭弹窗。桌面与窄屏都验证。

## 7. 不在范围

不实现定时自动预检、自动选择模型、模型遍历、自动重试、自动创建 Provider、凭据导入行为改变、历史批次持久化或真实账户自动 smoke。不修改既有管理批量预检、用量刷新和请求路由的产品语义。

## 8. 实现落点与调整记录

- 单账户请求继续使用原诊断入口，新增 mode/prompt；旧 Provider 请求不要求新增 mode。
- `forwardAttempt` 增加仅内部可设的 accountPreflight 标记，复用请求适配与凭据路径；连接描述不登记为 Provider，账户预检使用管理客户端副本且禁止重定向。
- `queue.AcquireGroupOnly` 共享既有账户资源组，不创建 Provider 队列，取消和释放均走既有组调度。
- `DiagnosticIdentity` 用账户对象与外部凭据替换边界检查诊断身份；正常自动刷新不误判成身份变化，排队后的旧调用票据在发出请求前复核。
- 批量协议使用扁平字段结构，兼容仓库严格 JSON 形状校验，不使用匿名嵌套字段。结果事件含 report，结束事件含 counts。
- 单/批前端复用诊断弹窗和消费确认逻辑；批量结果逐项更新当前账户视图，未收到结果只标未知。
- 账户目录缓存于管理删除成功后及目录请求前后清理，凭据世代隔离旧内容；迟到目录结果不得跨身份返回。
- 目录、默认/自定义内容与流内错误的 smoke 采用 httptest 固定官方主机重写，完全不连接真实上游。

- 读取边界修正：账户目录 GET 与既有 Provider 目录一致，允许没有 Origin 的同源浏览器读取，保留 Host 与跨站校验；刷新 POST 仍必须携带可信 Origin，补充对应回归。
