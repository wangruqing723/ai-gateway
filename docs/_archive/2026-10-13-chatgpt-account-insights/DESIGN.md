# 设计：ChatGPT 账号授权与用量信息

状态：已通过 `2455a3c` 集成；2026-11-01 使用者确认既有验收完成，文档已按当前代码补正。

## 背景

本需求实现前，账号管理 API 主要提供邮箱、套餐、授权状态、访问令牌到期时间、最近刷新时间和绑定提供商。当前实现已把首次授权时间、可选订阅周期及用量快照纳入安全视图并展示在管理页；“尚未进入安全视图”仅是历史背景，不再描述当前状态。

`ExpiresAt` 表示访问令牌的到期时间。它通常会通过 refresh token 自动续期，因此不能把它当作账号已授权时长或 ChatGPT 订阅截止日期。

## 数据流

1. OAuth 首次授权成功时记录 `AuthorizedAt`。已有关联账号重新授权时保留原值；后续导入功能以本次导入时间作为新账户的 `AuthorizedAt`，不代表外部工具中的原始授权日期。
2. 解析 ID token / access token 中已有的套餐类型和可选订阅日期声明；缺少声明时不生成猜测值。
3. 管理 API 使用服务端凭据请求 ChatGPT usage 接口，解析实际返回的各限额窗口和可选 credits 信息。
4. 账号列表提供最近一次的安全用量快照。快照保留在内存，并通过现有原子保存流程写入账户文件；页面在缺失快照或超过 30 分钟时触发批量刷新。后端以最近尝试时间判定缓存有效期，旧记录回退到 `LastCheckedAt`。
5. UI 显示有效比例窗口的剩余百分比和重置时间。手动刷新可立即重新查询；单个账号失败保留原快照，更新该账号的尝试时间和安全错误，不影响其他账号。

## 字段与展示语义

- **首次授权时间 / 已授权时长**：来自持久化的 `AuthorizedAt`。新账户首次完成 OAuth 时记录；后续新增的导入功能对新导入账户记录本次导入时间。已有记录重新授权时不覆盖，不推算外部工具中的原始授权日期。
- **套餐/账号类型**：UI 优先使用 usage 的 `planType`，缺失时回退到 token claim 中保存的 `chatgpt_plan_type` / `plan_type`；未知时显示“未知”，不把 usage 类型当作订阅有效期。
- **订阅周期**：可选的 `chatgpt_subscription_active_start`、`chatgpt_subscription_active_until` 声明；它们与用量窗口重置时间分别展示。此类 claim 是可选上游元数据，不能作为每个账号都有的保证。
- **剩余用量**：仅输出存在可解析 `used_percent` 的受支持窗口，剩余值为 `100 - used_percent` 并限制在 0–100；缺少有效比例时不返回整个窗口，重置时间和窗口长度也不单独展示。不硬编码某个配额值。
- **Credits**：当前只提取并显示可解析的 `balance` 余额，不展示其他 credits 标记；缺少余额时不显示该项。
- **查询状态**：记录最近查询时间及安全的错误摘要；不包含上游原始响应、token 或敏感请求头。
- **历史账号**：旧账号若缺少 `AuthorizedAt`，页面显示“未知”。不从文件修改时间、token 刷新时间或本次重新授权时间推算。

## 后端设计

- 扩展已持久化的 account 元数据及 `AccountView` 安全结构；凭据字段继续仅留在服务端。
- 增加 usage client，复用 OAuth 管理器持有的账号凭据，并在请求前确认 access token 有效；用量查询及它触发的刷新均使用管理器 OAuth 客户端，不使用当前 Provider 客户端。
- 对 usage 请求设置 15 秒超时、批量并发上限 3 和 30 分钟缓存；列表读取只返回已有快照，不等待上游。每账户查询串行化，缓存快照和尝试/成功状态随账户文件保存，落盘失败保留新内存快照。
- 以每个账号为单位记录错误，失败保留该账户旧窗口/credits 与最近成功时间，成功账户返回新快照。
- 使用 ChatGPT Web backend 的 usage 接口作为兼容实现。该接口不是本项目可依赖的稳定公开 API，响应字段和可用性可能变化；解析逻辑应允许字段缺失，并使失败只影响用量卡片。

## 前端设计

- 在现有账号卡片中保留状态和绑定提供商，并增加“已授权时长”“账号/套餐类型”“用量”信息区。
- 按窗口逐项显示剩余百分比和重置时间；没有数据时显示获取中、尚无数据或查询失败状态。
- 增加页面级“刷新用量”按钮。账号列表初次加载后，只刷新无缓存或超过缓存期限的数据；刷新过程不阻塞账号操作。
- 保持窄屏布局可读；不在 UI 中暴露令牌或原始 claims。
