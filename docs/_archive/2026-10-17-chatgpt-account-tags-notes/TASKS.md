# ChatGPT OAuth 账户标签和备注

状态：实现阶段已完成并集成；专项回归缺口移交统一跟踪；2026-11-01 归档记录已补全

## 目标

在仪表盘管理 ChatGPT OAuth 账户时，可以为每个账户设置多个标签和一段备注；重启网关后仍保留。

## 范围与约定

- 标签是账户级自由文本列表，备注是账户级多行文本。
- 标签显示在账户列表行；标签和备注在可展开的账户详情中编辑。
- 元数据存入现有 `data/chatgpt-accounts.json` 账户记录，不写入 Provider 配置，也不涉及 OAuth 凭据。
- 旧账户文件没有这两个字段时按空标签、空备注读取，不需要单独迁移。
- API 更新元数据时复用账户管理器的原子持久化；失败时回滚内存变更。
- 标签输入数组最多 20 项（清理空项和去重前检查）、每个修剪后的标签最多 32 个 Unicode 字符；首尾空白会清理，空标签忽略，重复标签不区分大小写去重并保留首次输入的大小写。备注最多 2000 个 Unicode 字符，除长度限制外原样保存。
- 标签和备注只属于网关本地账户数据，不加入面向其他工具的 OAuth 凭据导出格式；外部导入的账户默认为空。

## 验收标准

- 新增、修改和清空标签/备注后，账户列表立即更新；重启后数据仍存在。
- 旧账户数据正常读取，账户普通 API 视图仍不暴露任何 OAuth 令牌。
- 无效长度、无效 JSON、未知账户和跨站请求被拒绝；持久化失败不会留下半更新的内存状态。
- 标签/备注不进入第三方兼容格式的导出文件。
