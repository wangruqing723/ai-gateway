# 本机敏感配置传输与普通查询分离

网关普通管理查询只提供脱敏视图，而备份／迁移需要真实凭据；若将明文并入普通查询，凭据暴露会扩散到页面常态加载、预览、日志和缓存。新的敏感导入导出采用独立、明确触发的本机同源 POST：明文导出只进入无缓存附件响应，预览和错误不返回配置原值，写入前必须校验并由使用者确认。

这是对“普通查询统一返回明文以方便下载”及“无 Origin 的自动化接口”的有意拒绝。当前管理面没有身份鉴权，本机同源检查和界面确认不能冒充认证；只面向可信本机或 SSH 本地转发，不支持公网直接暴露。

后续同类需求复用上述 Interface 的安全约束与取舍依据，不因此预建通用迁移 Module。既有 OAuth 导入导出不在本次改造范围，不宣称其已经符合新增端点的全部限制。
